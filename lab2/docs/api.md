# Документация API (Лабораторная работа №2)

В рамках работы реализовано 3 GET-эндпоинта.

## 1. Простой текст
**Эндпоинт:** `GET /api/text`  
**Описание:** Возвращает простое текстовое сообщение.  
**Пример ответа (200 OK):**
Привет! Это мой первый сервер на Node-RED.

---

## 2. JSON-информация
**Эндпоинт:** `GET /api/info`  
**Описание:** Возвращает JSON-объект с информацией об авторе и статусе.  
**Пример ответа (200 OK):**
```json
{
  "author": "Puzhuk",
  "status": "Успешно"
}
```

---

## 3. Запрос с параметром (успех и ошибка)
**Эндпоинт:** `GET /api/items`  
**Параметры (Query):** `id` (обязательный параметр).  
**Описание:** Ищет товар по переданному ID. Если параметр не передан, возвращает ошибку 400.  

**Пример успешного запроса (200 OK):** `/api/items?id=777`  
**Ответ:**
```json
{
  "message": "Товар найден",
  "itemId": "777"
}
```

**Пример запроса с ошибкой (400 Bad Request):** `/api/items`  
**Ответ:**
```json
{
  "error": "Bad Request. Вы не передали параметр ?id="
}
```
