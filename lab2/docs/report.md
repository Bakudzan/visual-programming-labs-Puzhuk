# Отчет по лабораторной работе №2. Node-RED

## 1. Краткое описание выполненного
В ходе работы был освоен low-code инструмент Node-RED. Настроен запуск сервера через Docker с пробросом volume для сохранения данных (persistence). Были собраны и протестированы базовые потоки данных, реализована логика ветвления, работа с HTTP-запросами (внешнее API и поднятие собственного веб-сервера), обмен сообщениями по протоколу MQTT. Также был настроен Dashboard (графики), Telegram-бот и чтение/запись локальных файлов. Успешно выполнена Ачивка №7 (Node-RED Projects + Git).

## 2. AI-промпты, которые использовались
1. Сгенерируй JS код для Node-RED (Function node), вычисляющий среднюю оценку студента, используя let/const, if/else, for, массивы и объекты.
2. Сгенерируй Mustache-шаблон для Template node, который принимает объект с именем и группой и выводит красиво отформатированный JSON.
3. Напиши логику проверки параметра URL (msg.payload.id) для создания собственного GET-эндпоинта с возвратом 200 OK или 400 Bad Request.

## 3. Освоенные ноды
- **Базовые:** inject, debug, function, change, switch, template
- **Сеть:** http request, http in, http response, mqtt in, mqtt out
- **Dashboard:** gauge, chart
- **Интеграции:** telegram receiver, telegram sender
- **Хранилище:** file, file in

## 4. Способ установки и версии
- **Способ установки:** Docker Desktop (через образ `nodered/node-red`)
- **Версия Node-RED:** v5.0.7
- **Версия Node.js:** v24.20.0

## 5. Выводы
Визуальное программирование в Node-RED позволяет невероятно быстро собирать прототипы интеграций, IoT-решений и веб-серверов. Основная сложность — правильная маршрутизация сообщений (`msg.payload`) между узлами. Применение Docker делает процесс развертывания независимым от ОС, а использование контекста и файловой системы позволяет сохранять данные между сессиями.
