\## 3. Сравнение версионирования (git diff)

Я добавил(а) новый шаг («Завершение поездки и оплата») в схему BPMN. При проверке изменений через git diff:

\* В текстовом формате .bpmn Git распознал код и подсветил зеленым новые добавленные строки (XML-теги задачи).
